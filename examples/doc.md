| Archivo                              | Qué hace y cómo está configurado                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|--------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`example_views.py`**               | Backend de referencia. Usa `TemplateView` para mostrar los listados por GET y responder las consultas DataTables por POST con `action=search`. Aplica restricciones por establecimiento/perfil, búsqueda con `Q`, filtros ColumnControl, ordenamiento y paginación. Devuelve JSON con `draw`, `recordsTotal`, `recordsFiltered`, `data` y opciones de filtros. También incluye creación y edición con clases `Standard`, un mixin para restringir unidades, eliminación por POST y generación de PDF con WeasyPrint. |
| **`example_datatable.html`**         | Plantilla del listado de consulta. Extiende `base.html`, incluye el menú lateral, CSRF y la tabla `#myTable` con ocho columnas. El cuerpo queda vacío porque los datos llegan por AJAX. Carga el JavaScript del listado.                                                                                                                                                                                                                                                                                             |
| **`example_datatable.js`**           | Inicializa DataTables con `serverSide: true`. Envía POST a la URL actual conservando los parámetros GET, incluye CSRF y `action=search`. Configura páginas de 10, 25, 50 o 100 registros, selección individual, responsive, búsqueda, orden descendente inicial e idioma español. Incluye exportaciones, recarga, limpieza y filtro ColumnControl para departamento. Renderiza la dirección como enlace a Maps cuando existe una URL válida.                                                                         |
| **`example_datatable_buttons.html`** | Plantilla administrativa. Agrega el botón **Nuevo Anexo** y una novena columna **Acciones**. Proporciona las URLs de edición y eliminación mediante atributos `data-*` y también variables JavaScript. Carga por separado los scripts de tabla y confirmación.                                                                                                                                                                                                                                                       |
| **`example_datatable_buttons.js`**   | Mantiene la configuración del listado anterior y agrega botones **Editar** y **Eliminar** por registro. Construye sus URLs reemplazando el identificador temporal `0`. La columna Acciones no permite búsqueda, ordenamiento ni ColumnControl y queda excluida de la selección de filas. Entrega al botón Eliminar el ID, nombre y URL mediante `data-*`.                                                                                                                                                            |
| **`example_form.html`**              | Formulario para creación y edición. Renderiza cada campo individualmente con su etiqueta y errores, usando una cuadrícula Bootstrap de hasta cuatro campos por fila. Incluye CSRF, errores generales, botones Volver/Cancelar/Guardar, título y texto de envío dinámicos. Carga el JavaScript del formulario.                                                                                                                                                                                                        |
| **`example_form.js`**                | Formatea el teléfono como `+569XXXXXXXX`, conservando hasta ocho dígitos después del prefijo. Además, inicializa Tom Select sobre los elementos `.tom-select`, utilizando las opciones existentes del formulario y el mensaje **“No se encontraron resultados”**. No configura búsqueda AJAX.                                                                                                                                                                                                                        |
| **`example_modal.js`**               | Gestiona la eliminación con **SweetAlert2**. Escucha los botones mediante delegación de eventos, muestra confirmación y carga, y envía un POST con CSRF mediante jQuery AJAX. Interpreta `success`, `status` y `message`, muestra el resultado y recarga la tabla conservando la página con `ajax.reload(null, false)`.                                                                                                                                                                                              |
